# Изменения: материалы, видео, CMS и SEO

## Главная и библиотека

- Убраны подписи рядов «Тексты» и «Видео» в «Идеи, которые работают».
- В каждом ряду главной по три карточки, независимая пагинация справа.
- У видео встроенный внешний плеер, обложка и один текстовый блок — заголовок. Описание под заголовком не выводится.
- «Посмотреть программы» и «Перейти в библиотеку» расположены вместе под обоими рядами.
- В библиотеку добавлены видеокарточки. Общая выдача чередует статьи и видео; есть фильтры типа, доступа, поиск и пагинация.
- Белый фон, типографика, логотип, основные разделы и правовые ссылки сохранены.

## CMS

- Новые карточки создаются как черновики; опубликованность и показ на главной управляются раздельно.
- У статей, видео и курсов есть дата публикации, ручное перемещение и настройка сортировки.
- Для каждого модуля главной задаётся общий лимит: все записи либо первые N. Размер страницы остаётся три карточки.
- У курса есть календарная дата начала и редактируемая текстовая замена; пустые даты дают «Дата набора уточняется».
- Добавлено редактирование фиксированных текстов интерфейса с поиском: названия кнопок, меню, подписи и содержательные формулировки, ранее зашитые в компоненты.
- SEO редактируется для разделов и отдельных статей / программ.
- Недостающие поля старых данных добавляются без перезаписи существующих CMS-правок.

## Техническая часть

- Общие функции отбора карточек, форматирования даты, проверки публикаций и нормализации адресов плееров.
- Плееры YouTube и ВК-Видео создаются по нажатию, без исполнения пользовательского HTML. Посторонние домены отклоняются.
- Черновики не попадают в публичный API; прямое чтение черновика статьи возвращает 404.
- Реальные адреса разделов Next.js с серверными метаданными и публичным содержанием; старые hash-ссылки сохранены через перенаправление.
- Сохранена отдельная статическая Worker-сборка; её сервер подставляет SEO из собственной D1 CMS. Основное серверное развёртывание — VPS.

## Проверки

Команды для воспроизведения:

```
npm run typecheck
npm run build:vps
npm run test:integration
npm run test:cms
npm run test:worker
npm run build
```

Проверки CMS покрывают сохранение SEO и текста интерфейса, черновики и прямой доступ, лимиты, сортировку, разбиение пяти записей по три, даты курсов, сохранение старых значений при добавлении настроек и запрет посторонних видеодоменов. Существующие проверки регистрации, сессий, клубного доступа, заявок и Worker сохранены.

В браузере проверены три карточки в каждом ряду, независимая пагинация видео, расположение ссылок и выдача библиотеки с тестовыми видеозаписями. Тестовые записи не включены в репозиторий. Реальное воспроизведение конкретных видео пользователя требует их доступных ссылок и разрешённого встраивания.

Подробная инструкция: [CMS_GUIDE.md](CMS_GUIDE.md).
