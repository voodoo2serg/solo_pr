# Соло-PR

Соло-PR — сообщество и цифровая платформа для специалистов по коммуникациям, которые становятся профессиональными партнёрами бизнеса. Собственная предметная экспертиза, понимание задач заказчика и сотрудничество с коллегами помогают перейти к самостоятельным рекомендациям и понятному результату.

Соло — не значит один. Сообщество развивает профессиональную поддержку, повышение квалификации и роль связей с общественностью и гуманитарного знания в бизнесе.

## Что есть на сайте

- Основные разделы: Идея, Сообщество, Обучение, Бизнесу.
- Каталог курсов с фильтрами и пагинацией; открытые и клубные материалы, видеопубликации. Календарь встреч доступен после авторизации.
- Коммуникационный аудит, кризисный консалтинг, личное сопровождение и экспресс-диагностика.
- Короткие заявки без регистрации: email, Telegram или MAX; имя необязательно, тема определяется выбранным курсом или услугой. Согласие на обработку данных обязательно; рекламная подписка не оформляется.
- Личный кабинет: подтверждённые покупки курсов, индивидуальные документы, сохранённые материалы, встречи, фото и настройки профиля.
- CMS для текстов, программ, видео, правовых документов, реквизитов, заявок и доступа участников.

Платёжная система и видеоконференции не подключены автоматически. Интерес к программе не считается покупкой. Администратор открывает доступ после подтверждения оплаты и добавляет ссылки на встречи и документы.

## Дизайн

Белый фон, локально поставляемые шрифты Golos Text и Unbounded, кирпичные акценты и пастельные плашки. Логотип извлечён из предоставленного владельцем PDF как вектор. Горная иллюстрация создана для проекта. Визуальные источники: site_sv и site_pr; исходные репозитории не изменялись.

## Технологии и два варианта размещения

**VPS:** Node.js 24, Next.js 16, React 19, SQLite и JSON-файл текстов. Сайт собирается через `npm run build:vps`; Dockerfile использует именно эту команду.

**Sites:** статическая клиентская сборка Next.js и Worker с Cloudflare D1. Команда `npm run build` создаёт `dist/client` и `dist/server`. Исходники Worker и миграций сохранены, но привязка к приватному размещению Sites в этот репозиторий не включена.

Базы VPS и Sites независимы. Миграция аккаунтов и паролей между ними не выполняется автоматически. На VPS пароли хешируются scrypt, в Worker — PBKDF2-SHA256. Данные пользователей не хранятся в репозитории.

## Развёртывание на VPS

Подробная инструкция с HTTPS, созданием администратора, резервным копированием и обновлениями: **[docs/VPS.md](docs/VPS.md)**.

Быстрый запуск приложения, если Docker Engine и Compose уже установлены:

```bash
git clone https://github.com/voodoo2serg/solo_pr.git
cd solo_pr
docker compose up -d --build
```

Приложение слушает только `127.0.0.1:3000`. Для браузерного входа и защищённых cookie настройте HTTPS-прокси по инструкции. Постоянные данные хранятся в Docker-томе `community-data`.

## Локальная разработка

```bash
npm ci --legacy-peer-deps
cp .env.example .env.local
npm run dev
```

Для HTTP-разработки задайте `COOKIE_SECURE=false`. Для production используйте `true` и HTTPS. Сайт: `http://localhost:3000`.

## Управление

Вход: `/#/login`. Редактор: `/#/admin`. Создайте администратора серверной командой по инструкции VPS. Обычная регистрация не выдаёт административных прав или членства в клубе.

Основные файлы:

- `src/components/views/` — страницы.
- `src/components/site/` — шапка, футер, формы, каталог, редакторские компоненты.
- `src/lib/server/` — SQLite, сеансы и первоначальные тексты VPS.
- `src/app/api/portal/[...path]/route.ts` — серверный API VPS.
- `src/lib/brand-content.ts` — фирменные реквизиты и одноразовые обновления контента.
- `worker/`, `db/`, `drizzle/` — вариант Sites/D1.
- `public/` — логотип, изображения и favicon.
- `scripts/admin.mjs` — создание администратора и сброс пароля.

## Проверки

```bash
npm run typecheck
npm run test:worker
npm run build:vps
npm run test:integration
```

Интеграционные тесты используют отдельные временные базы, проверяют авторизацию, изоляцию кабинетов, закрытые материалы, редактор, документы и заявки. Рабочие пользовательские данные не затрагиваются.

## Данные и права

Реквизиты оператора и почта предоставлены владельцем. Telegram: https://t.me/prvodo. Ссылка MAX пока не задана; её можно добавить в CMS. Политики данных и cookie доступны из футера. Перед внешним запуском проверьте соответствие правовых документов фактическому размещению и подключённым сервисам.

Логотип, фотографии, иллюстрация и авторские тексты не объявляются свободными для стороннего использования. Лицензии шрифтов поставляются их npm-пакетами. При повторном использовании материалов учитывайте права их владельцев.

Тексты и видео на главной имеют независимую пагинацию по две публикации на страницу. Тема оформления переключается для всего сайта; у вошедшего участника выбор сохраняется в профиле.

## CMS: материалы, видео и SEO

[Инструкция администратора](docs/CMS_GUIDE.md) · [Описание изменений](docs/CHANGES_CMS_MEDIA_SEO.md).

Редактор `/admin` управляет текстами, программами, публикациями, плеерами YouTube / ВК и SEO. Основные разделы имеют обычные URL с серверными метаданными; старые `/#/...` ссылки продолжают работать. Для основной установки используйте VPS-сборку `npm run build:vps` и постоянный каталог данных.
